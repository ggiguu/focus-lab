# FOCUS LAB · Studio 02

[실행하기](https://ggiguu.github.io/focus-lab/) · 설치와 AI API 없이 브라우저에서 실행되는 한국어 3D 카메라·심도 실험실입니다.

## 기능

- 인물 1~5명, 남성·여성·혼합·개별 모델 선택, 인물별 초점 선택
- 나란히/깊이 차이/대화 배치, 인물 간격과 바라보는 방향 조절
- ELS / LS / MLS / MS / MCU / CU / ECU 샷 자동 맞춤
- 아이 레벨 / 로우 / 하이 / 버드아이 / 수직 탑 / 더치 앵글과 직접 조절
- 카메라 방위각 360도, 인물 방향 및 카메라 롤
- 16:9 / 3:2 / 4:3 / 1:1 / 9:16 / 2.39:1 화면비, 3분할 격자와 안전 영역
- 연동 측면도·탑뷰, 탑뷰 카메라 드래그와 인물 초점 선택
- 풀프레임/APS-C/MFT, 렌즈·조리개·거리·높이 및 다층 배경 조절
- A/B 설정 비교, PNG 및 JSON 다운로드, 마지막 설정 자동 저장
- 모바일 설정 서랍, 반응형 뷰포트, 전체 화면

렌더링과 심도 처리는 방문자 기기의 WebGL에서 실행됩니다. AI API·계정 토큰·사진 업로드 기능은 사용하지 않습니다. 폰트만 Google Fonts에서 불러오며 3D 엔진과 모델은 로컬 번들입니다.

## 실행 / 테스트

Node.js가 있다면 `npm test`로 카메라·센서 게이트·배치·샷 계산을 검증합니다. 패키지 설치가 필요 없습니다.

```sh
python3 -m http.server 3000 --directory docs
# http://localhost:3000/
```

HTML을 file://로 직접 여는 대신 HTTP 서버를 사용하세요. GitHub Pages는 main 브랜치의 /docs로 배포합니다. 변경을 main에 올리면 Pages가 갱신됩니다.

## 계산과 제약

`docs/camera-rig.js`가 인물 위치, 카메라, 시선, 프레이밍, 센서 게이트와 심도의 공통 계산을 제공합니다. 사진과 배치도는 같은 카메라 행렬을 사용합니다. 초점은 선택한 인물의 얼굴 표면을 기준으로 하며 초점 깊이는 카메라 시선 축으로 계산합니다. 샷 자동 맞춤은 현재 앵글을 가능한 범위에서 유지하며 거리·높이·주시점을 변경합니다. 이후 수동 렌즈/거리/화면비 조절은 자유 구도로 전환됩니다.

화면비는 실제 센서 크기 안에서 게이트를 잘라 적용하며 세로 화면은 센서 방향을 바꿉니다. 깊이 텍스처 기반 심도는 렌즈 고유 보케·회절·왜곡까지 재현하지 않는 학습용 근사입니다. 여러 인물을 배치했을 때 카메라가 인물 사이로 들어가거나 선택 인물이 뒤에 있으면 방향·거리를 조정해야 합니다. 측면도는 공간을 투영한 자동 축척이고 탑뷰는 인물·카메라의 평면 배치를 보여줍니다.

배경 기준 거리는 벤치까지입니다. 화단·벤치·나무·카페·먼 풍경은 각각 다른 비율로 이동합니다. 앱은 조작할 때만 다시 렌더링하며 다수 인물 비교 시 골격 복제본을 재사용합니다. 저사양 기기에서는 그래픽 성능 차이가 있습니다.

## 검증

단위 테스트는 센서 게이트/화면비, 방향·높이·수직 앵글과 초점 깊이, 여러 인물 배치, 샷 맞춤, 입력 범위 및 잘못된 초점 위치를 검증합니다. 데스크톱·모바일 Chromium/SwiftShader에서 실제 WebGL 장면, 남녀 모델·다인 배치·초점, 격자·화면비·앵글·방향, A/B, 탑뷰 드래그, PNG 저장과 설정 복원을 확인했습니다.
