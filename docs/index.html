직접 움직이며 구도를 잡아보세요

드래그 / Drag
미리보기에서 왼쪽 버튼으로 끌면 인물 주위를 회전합니다. 방향키로도 조절할 수 있어요.
화면 이동 / Pan
Shift를 누르고 끌거나 오른쪽 버튼으로 끌면 카메라와 주시점이 함께 이동합니다.
확대·축소 / Zoom
마우스 휠 또는 + / − 키를 사용하세요. 모바일은 한 손가락 회전, 두 손가락 확대·축소 및 이동을 지원합니다.
초점 / Focus
인물을 짧게 클릭하거나 탑뷰의 인물을 눌러 초점을 선택합니다. A 화면은 비교 기준으로 고정됩니다.
프롬프트 / Prompt
촬영 정보는 한글·영문으로 표시됩니다. 아래 프롬프트에서 언어를 고른 뒤 복사하세요. PNG 저장에는 현재 표시 정보와 격자도 포함됩니다.

우측 상세 설정은 그대로 사용할 수 있습니다. 자석 스냅은 드래그를 놓을 때 가까운 45° 방향·아이레벨에 맞춥니다.
